# ۰۶ — انتشار

از ساخت کلید امضا تا گذاشتن بازی در کافه بازار، مایکت و گوگل‌پلی.

</div>

## قدم ۱ — آماده‌سازی

### نسخه را بالا ببر

در `app/build.gradle.kts`:

```kotlin
versionCode = 2        // هر انتشار یکی زیاد شود (عدد صحیح)
versionName = "1.1"    // چیزی که کاربر می‌بیند
```

⚠️ `versionCode` باید از نسخه قبلی **بزرگ‌تر** باشد وگرنه فروشگاه قبول نمی‌کند.

### نام و آیکون

- نام برنامه: `app/src/main/res/values/strings.xml`
- آیکون: `app/src/main/res/drawable/ic_launcher_foreground.xml` و رنگ پس‌زمینه در
  `values/ic_launcher_background.xml`

برای آیکون بهتر: در اندروید استودیو راست‌کلیک روی پوشه `res` ←
**New ← Image Asset** ← عکس خودت را بده.

### بخش‌های نیازمند سرور

مطمئن شو در `index.html` همه چیز در `FEATURES` که سرور می‌خواهد `false` است،
تا کاربر دکمه‌ای نبیند که کار نمی‌کند.

## قدم ۲ — ساخت کلید امضا

**این کار را فقط یک بار در تمام عمر برنامه انجام می‌دهی.**

```bash
keytool -genkey -v -keystore sultan.jks -keyalg RSA \
        -keysize 2048 -validity 10000 -alias sultan
```

اگر `keytool` را پیدا نکرد، از پوشه جاوای اندروید استودیو اجرایش کن:

```
C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe
```

سؤال‌هایی می‌پرسد (نام، شهر، کشور). می‌توانی هرچه می‌خواهی بنویسی.

> 🔴 **خیلی مهم:** فایل `sultan.jks` و رمزش را برای همیشه نگه دار. اگر گمشان کنی،
> **دیگر هرگز نمی‌توانی برنامه‌ات را در فروشگاه به‌روزرسانی کنی** و باید با نام
> بسته جدید از صفر شروع کنی. یک کپی در فضای ابری و یک کپی روی حافظه جدا بگذار.

---

## قدم ۳ — معرفی کلید به پروژه

فایل `keystore.properties.example` را کپی کن، اسمش را بگذار `keystore.properties`
(کنار `settings.gradle.kts`) و پرش کن:

```properties
storeFile=C:/keys/sultan.jks
storePassword=رمزی که گذاشتی
keyAlias=sultan
keyPassword=رمزی که گذاشتی
```

نکته‌ها:
- در ویندوز هم می‌توانی از `/` استفاده کنی
- این فایل در `.gitignore` هست و در گیت نمی‌رود
- اگر فایل نباشد، بیلد نمی‌شکند؛ فقط خروجی بدون امضا می‌شود

## قدم ۴ — ساخت خروجی

```bash
./gradlew assembleRelease     # APK — برای بازار، مایکت، نصب مستقیم
./gradlew bundleRelease       # AAB — برای گوگل‌پلی
```

خروجی‌ها:

```
app/build/outputs/apk/release/app-release.apk
app/build/outputs/bundle/release/app-release.aab
```

### بررسی امضا

```bash
$ANDROID_HOME/build-tools/36.0.0/apksigner verify --print-certs \
    app/build/outputs/apk/release/app-release.apk
```

اگر اسم گواهی را نشان داد، امضا درست است.

### تست نسخه نهایی

**حتماً** فایل release را روی یک گوشی واقعی نصب کن و کامل تست کن. گاهی چیزی که
در نسخه debug کار می‌کند، در release مشکل دارد.

## قدم ۵ — کافه بازار

1. برو به [pishkhan.cafebazaar.ir](https://pishkhan.cafebazaar.ir) و ثبت‌نام کن
   (رایگان، با شماره موبایل ایران)
2. **افزودن برنامه جدید** ← فایل `app-release.apk` را آپلود کن
3. اطلاعات را پر کن:
   - **نام:** سلطان معما
   - **توضیح کوتاه:** بازی پازل و سرگرمی فارسی
   - **توضیح کامل:** بخش‌های بازی را بنویس
   - **دسته‌بندی:** بازی ← معما و فکری
   - **رده سنی:** همه
4. **تصویرها:** حداقل ۳ اسکرین‌شات + یک آیکون ۵۱۲×۵۱۲
5. **قیمت:** رایگان یا پولی
6. ارسال برای بررسی — معمولاً ۱ تا ۳ روز کاری

### گرفتن اسکرین‌شات

با گوشی از بازی عکس بگیر، یا در اندروید استودیو از دکمه دوربین در پنل
Running Devices استفاده کن.

---

## قدم ۶ — مایکت

1. [panel.myket.ir](https://panel.myket.ir) ← ثبت‌نام
2. همان مراحل بازار: آپلود APK، پر کردن اطلاعات، اسکرین‌شات
3. بررسی معمولاً ۱ تا ۲ روز

می‌توانی **همان فایل APK** را در هر دو فروشگاه بگذاری.

---

## قدم ۷ — گوگل‌پلی

1. [play.google.com/console](https://play.google.com/console) ← ثبت‌نام
   (**۲۵ دلار یک‌بار**، نیاز به کارت بین‌المللی)
2. **Create app** ← نام، زبان، رایگان/پولی
3. فایل **AAB** را آپلود کن (گوگل‌پلی APK قبول نمی‌کند)
4. فرم‌های اجباری را پر کن:
   - **Privacy policy:** یک صفحه وب لازم است. چون بازی هیچ داده‌ای جمع نمی‌کند،
     متن ساده کافی است (نمونه پایین)
   - **Data safety:** همه را «داده‌ای جمع نمی‌شود» بزن
   - **Content rating:** پرسشنامه را پر کن
   - **Target audience**
5. انتشار — بررسی ممکن است چند روز تا دو هفته طول بکشد

### نمونه متن حریم خصوصی

> **حریم خصوصی — سلطان معما**
>
> این بازی هیچ اطلاعات شخصی از کاربران جمع‌آوری، ذخیره یا ارسال نمی‌کند.
> پیشرفت بازی فقط روی دستگاه خود کاربر ذخیره می‌شود و به هیچ سروری فرستاده
> نمی‌شود. بازی به اینترنت دسترسی ندارد و هیچ تبلیغاتی نمایش نمی‌دهد.
>
> تنها مجوز درخواستی، لرزش (VIBRATE) است که برای بازخورد لمسی استفاده می‌شود.
>

## به‌روزرسانی بعدی

هر بار که می‌خواهی نسخه تازه بدهی:

1. `versionCode` را یکی زیاد کن، `versionName` را عوض کن
2. `./gradlew assembleRelease` (یا `bundleRelease`)
3. فایل تازه را در فروشگاه آپلود کن
4. **حتماً با همان کلید قبلی امضا شده باشد**
