## مرحله تازه

مرحله‌ها **خودکار ساخته می‌شوند**. برای بیشتر کردنشان فقط یک عدد را عوض کن.

در `index.html` بخش ۲:

```js
var CFG = {
  TOTAL_STAGES:100,   // ← این را ۲۰۰ کن
};
```

یا از پنل مدیریت ← اقتصاد ← «تعداد کل مراحل».

هر مرحله از روی شماره‌اش ساخته می‌شود، پس مرحله ۱۵۷ همیشه دقیقاً یکسان است و
هیچ‌جا ذخیره نمی‌شود.

## تصویر تازه برای بخش حدس

### راه آسان (بدون کد)
پنل مدیریت ← تب محتوا ← فرم «تصویر تازه» ← ایموجی + نام + دسته ← افزودن

### راه کدی
در بخش ۹ به آرایه `ITEMS` اضافه کن:

```js
['🥁','طبل','thing'],
```

**دسته‌های موجود:**

| کد | نام فارسی |
|---|---|
| `animal` | حیوانات |
| `food` | غذاها |
| `place` | مکان‌های معروف |
| `thing` | وسایل |
| `fantasy` | شخصیت‌های خیالی |
| `sport` | ورزش |
| `nature` | طبیعت |
| `car` | خودرو |
| `fruit` | میوه‌ها |
| `job` | شغل‌ها |

⚠️ هر دسته باید **حداقل ۴ تصویر** داشته باشد تا بشود گزینه‌های اشتباه ساخت.

### دسته تازه

در بخش ۹ به `CATS` اضافه کن:

```js
var CATS={
  animal:'حیوانات',
  music:'سازها',      // ← تازه
};
```

بعد چند تصویر با دسته `music` اضافه کن.

## شیء تازه برای صحنه‌ها

سه قدم، همه در بخش ۱۰.

### قدم ۱ — تابع رسم

به شیء `PROPS` اضافه کن. مبدأ مختصات **پایین وسط** شیء است و شیء به سمت بالا
(y منفی) کشیده می‌شود:

```js
umbrella:function(o,C,D){
  // C رنگ اصلی، D رنگ فرعی
  var s='<rect x="-0.8" y="-14" width="1.6" height="14" fill="#7a4a21"/>';
  s+='<path d="M-11,-14 A11,9 0 0 1 11,-14 Z" fill="'+C+'"/>';

  // o.v شماره حالت است (۰ و ۱ و ۲) — برای تفاوت «تغییر شکل»
  if(o.v===1) s+='<path d="M-11,-14 h22" stroke="'+D+'" stroke-width="1.4"/>';
  if(o.v===2) s+='<circle cx="0" cy="-15" r="3" fill="'+D+'"/>';

  // o.d برای تفاوت «تغییر جزئیات»
  if(o.d) s+='<circle cx="0" cy="-17" r="1.8" fill="'+D+'"/>';

  return s;
},
```

**قانون‌ها:**
- اندازه معمولی: حدود ۲۰ تا ۳۰ واحد ارتفاع (کل صحنه ۳۰۰×۲۰۰ است)
- حتماً هر سه حالت `o.v` را پشتیبانی کن (لازم نیست خیلی فرق کنند)
- حتماً `o.d` را پشتیبانی کن
- فقط SVG ساده: `rect` `circle` `ellipse` `path` `polygon` `line`

### قدم ۲ — مشخصات

```js
// در META
umbrella:{r:13, oy:-9, f:0},
//         │      │     └ آیا قرینه‌شدن (چپ/راست) برایش معنی دارد؟
//         │      └ مرکز دیداری نسبت به مبدأ (برای دایره پیدا کردن)
//         └ شعاع لمس

// در COL — محدوده رنگ تصادفی
umbrella:[0,360, 70,90, 55,66],
//        │      │      └ روشنایی کم و زیاد
//        │      └ اشباع کم و زیاد
//        └ رنگ‌مایه کم و زیاد (۰ تا ۳۶۰)
```

### قدم ۳ — گذاشتن در تم

اسم شیء را در لیست `land` (روی زمین) یا `air` (در آسمان) یکی از تم‌ها بنویس:

```js
{id:'beach', name:'ساحل', …
 land:['boat','ball','shell','umbrella']},
```

### تست کردن

پنل مدیریت ← ابزار ← پیش‌نمایش صحنه، یا در Console مرورگر:

```js
SM.diff(3)   // چند بار بزن تا شیء تازه را ببینی
```

## تم تازه

در بخش ۱۰ به `THEMES` اضافه کن:

```js
{id:'forest', name:'جنگل',
 sky:[[150,60,55],[120,50,75]],    // رنگ آسمان: [بالا، پایین] به HSL
 ground:[100,40,32],                // رنگ زمین (اگر زمین ندارد: null)
 gy:130,                            // ارتفاع خط افق (۰ بالا، ۲۰۰ پایین)
 air:['bird','cloud','butterfly'],  // شیءهای شناور
 land:['tree','bush','flower']}     // شیءهای روی زمین
```

تم‌ها به ترتیب بین مرحله‌ها می‌چرخند، پس تم تازه خودکار وارد بازی می‌شود.

### پس‌زمینه مخصوص

اگر تمت جزئیات خاصی می‌خواهد (مثل ستاره‌های تم فضا)، در تابع `bg()` یک شرط
اضافه کن:

```js
if(th.id==='forest'){
  for(i=0;i<12;i++)
    s+='<ellipse cx="'+q(r()*300)+'" cy="'+(th.gy+4)+'" rx="14" ry="5" fill="rgba(0,0,0,.12)"/>';
}
```

## مأموریت تازه

در بخش ۷ به `MISSIONS` اضافه کن:

```js
{id:'coins', e:'🪙', t:'۵۰۰ سکه جمع کن', goal:500, coins:200, score:0}
```

بعد جایی که مأموریت باید پیشرفت کند، این را صدا بزن:

```js
mission('coins', n);   // n مقدار پیشرفت
```

مثلاً در تابع `addCoins`:

```js
function addCoins(n){
  S.coins = Math.max(0, S.coins + n);
  if(n>0){ Sfx.coin(); mission('coins', n); }
  save();
}
```

## صدای تازه

در بخش ۴ به `Sfx` اضافه کن. صداها با فرکانس ساخته می‌شوند:

```js
levelUp:function(){
  tone(600, 900, 0.15, 'triangle', 0.14, 0);
  tone(900, 1200, 0.20, 'sine', 0.12, 0.14);
}
//    │    │     │      │         │     └ تأخیر (ثانیه)
//    │    │     │      │         └ بلندی (۰ تا ۱)
//    │    │     │      └ شکل موج: sine, triangle, square, sawtooth
//    │    │     └ مدت (ثانیه)
//    │    └ فرکانس پایان
//    └ فرکانس شروع
```

بعد هرجا لازم شد: `Sfx.levelUp();`
