# ۰۳ — پنل مدیریت (سایت لپ‌تاپ)

پنل مدیریت یک **سایت جداست** که روی لپ‌تاپ خودت اجرا می‌شود، نه داخل بازی.
با آن تنظیمات و محتوای بازی را عوض می‌کنی و یک فایل `config.js` می‌سازی که
داخل بازی می‌گذاری.

</div>

---

## چرا جدا از بازی؟

| داخل بازی بود | حالا جداست |
|---|---|
| حجم برنامه بیشتر بود | برنامه سبک‌تر شد (۴۰ کیلوبایت کمتر) |
| کاربر می‌توانست پیدایش کند | کاربر اصلاً چیزی از آن نمی‌بیند |
| تنظیم روی گوشی خودت بود | تنظیم روی همه گوشی‌ها اعمال می‌شود |
| کار با صفحه کوچک سخت بود | صفحه بزرگ لپ‌تاپ، جدول و فرم راحت |

---

## اجرا کردن پنل

فایل زیر را روی لپ‌تاپت **دوبار کلیک کن** تا در مرورگر باز شود:

```
admin-panel/index.html
```

همین. نه نصب می‌خواهد، نه اینترنت، نه سرور.

### بار اول
یک رمز ۴ تا ۱۲ رقمی می‌سازی و یک **کد بازیابی** می‌گیری — یادداشتش کن.

### بارهای بعد
رمز را وارد می‌کنی. اگر چند بار اشتباه بزنی، ورود موقتاً قفل می‌شود
(۳ خطا ← ۳۰ ثانیه، ۵ خطا ← ۳ دقیقه، ۷ خطا ← ۳۰ دقیقه).

> قفل پنل اختیاری است. اگر لپ‌تاپ شخصی خودت است، در بخش «امنیت» می‌توانی
> خاموشش کنی.

---

## چرخه کار

```
۱. پنل را باز کن
۲. چیزی را عوض کن (قیمت، سختی، تصویر، …)
۳. دکمه «📤 ساخت config.js» را بزن → فایل دانلود می‌شود
۴. فایل را در این مسیر جای‌گزین کن:
      app/src/main/assets/config.js
۵. بازی را دوباره بساز:  ./gradlew assembleDebug
```

کارهای نیمه‌تمام در خود مرورگر ذخیره می‌شوند، پس اگر پنل را ببندی چیزی از دست
نمی‌رود.

## بخش‌های پنل

### 🎮 بازی
نام بازی، نام تیم و شماره نسخه — همان‌هایی که در صفحه اصلی و «درباره ما»
دیده می‌شوند.

### 💰 اقتصاد

| تنظیم | پیش‌فرض |
|---|---|
| راهنمای تفاوت | ۵۰ سکه |
| حذف یک گزینه | ۵۰ سکه |
| واضح‌تر کردن تصویر | ۸۰ سکه |
| ادامه بعد از شکست | ۱۰۰ سکه |
| پر کردن جان‌ها | ۱۵۰ سکه |
| بیشترین جان | ۵ |
| شارژ هر جان | ۱۰ دقیقه |
| تعداد مراحل هر بخش | ۱۰۰ |
| امتیاز لازم هر سطح | ۸۰۰ |
| ضریب سکه / امتیاز | ۱ |

> ضریب‌ها سرعت پیشرفت بازیکن را تنظیم می‌کنند. ۲ یعنی دو برابر جایزه.

### 🎚 سختی
مرز درجه‌ها (آسان/متوسط/سخت)، زمان مرحله‌ها، تعداد تفاوت‌ها و شلوغی صحنه.

پایین صفحه یک **پیش‌نمایش زنده** هست که با هر تغییر نشان می‌دهد مرحله‌های
۱، ۲۵، ۵۰، ۷۵ و ۱۰۰ چقدر سخت می‌شوند. قبل از ساخت فایل حتماً نگاهش کن.

### 🖼 محتوا
بانک تصویرهای بخش «حدس تصویر»:
- افزودن: ایموجی + نام فارسی + دسته
- جست‌وجو و فیلتر بر اساس دسته
- ویرایش ✏️ و حذف 🗑
- شمارش هر دسته (اگر دسته‌ای کمتر از ۴ تصویر داشته باشد، قرمز نشان داده می‌شود)

### 🎯 مأموریت و پاداش
هدف، متن و جایزه هر چهار مأموریت روزانه + مقدار سکه هر یک از ۷ روز پاداش.

### 🧩 قابلیت‌ها
کلید روشن/خاموش برای بخش‌هایی که به سرور نیاز دارند (رتبه‌بندی، فروشگاه،
بازی آنلاین، تورنمنت و…). خاموش = در بازی اصلاً دیده نمی‌شود.

### 📤 خروجی
- **دانلود config.js** — فایل نهایی
- **کپی متن** — اگر می‌خواهی دستی جای‌گذاری کنی
- **خواندن config.js موجود** — برای ادامه دادن روی تنظیمات قبلی
- **بازنشانی** — برگرداندن همه چیز به پیش‌فرض

### 📝 متن فروشگاه
متن آماده برای مایکت، کافه بازار و گوگل‌پلی می‌سازد: عنوان کوتاه، توضیح کامل و
کلمات کلیدی. با دکمه کپی بردار و در پنل فروشگاه بچسبان.
(نسخه آماده: [۰۸ — متن فروشگاه](08-store-listing.md))

### 🛡 امنیت
روشن/خاموش کردن قفل پنل، زمان بسته شدن نشست، تغییر رمز و گزارش کارها.

## فایل config.js چه شکلی است؟

```js
window.SULTAN_CONFIG = {
  "v": 1,
  "team": { "name": "SMRx", "game": "سلطان معما", "version": "۱٫۲" },
  "cfg":  { "HINT_COST": 50, "MAX_LIVES": 5, "TOTAL_STAGES": 100, ... },
  "d":    { "baseTime": 100, "diffBase": 3, ... },
  "mul":  { "coin": 1, "score": 1 },
  "features": { "leaderboard": false, ... },
  "missions": [ ... ],
  "daily":    [ ... ],
  "items":    [ ["🐱","گربه","animal"], ... ]
};
```

بازی این فایل را موقع باز شدن می‌خواند. هر چیزی که در آن نباشد، مقدار پیش‌فرض
خودش را نگه می‌دارد. اگر فایل خالی باشد (`{ v: 1 }`)، بازی دقیقاً با تنظیمات
پیش‌فرض اجرا می‌شود.

---

## نکته‌های مهم

⚠️ **پنل به بازی وصل نیست.** تا وقتی فایل را جای‌گزین نکنی و بازی را دوباره
نسازی، هیچ تغییری در برنامه دیده نمی‌شود.

⚠️ **بانک تصویرها در دو جاست:** پیش‌فرض‌ها هم در بازی هستند و هم در پنل. وقتی
از پنل فایل می‌سازی، لیست پنل جای لیست بازی را می‌گیرد. پس بعد از اولین بار،
پنل مرجع اصلی محتوا است.

⚠️ **پیشرفت بازیکن‌ها را پنل عوض نمی‌کند.** آن روی گوشی خود بازیکن ذخیره است.
