# تست‌های خودکار

این تست‌ها بازی را در یک مرورگر واقعی (Chromium) باز می‌کنند و مثل یک آدم واقعی
با آن بازی می‌کنند: روی تفاوت‌ها کلیک می‌کنند، گزینه انتخاب می‌کنند، رمز وارد
می‌کنند و نتیجه را بررسی می‌کنند.

## اجرا

```bash
npm install playwright
npx playwright install chromium

node tests/game.test.js     # ۳۳ تست بازی
node tests/admin.test.js    # ۲۷ تست پنل مدیریت و امنیت
```

اگر Chrome را جای دیگری داری:

```bash
CHROME_PATH=/path/to/chrome node tests/game.test.js
```

## چه چیزهایی بررسی می‌شوند

### `game.test.js`
- باز شدن بازی و پیام خوش‌آمد و پاداش روزانه
- بازی کردن کامل یک مرحله تفاوت (کلیک روی هر تفاوت)
- جریمه لمس اشتباه، راهنما، شمارش زمان
- بخش حدس: باز شدن تدریجی تصویر، حذف گزینه، واضح‌تر کردن
- کم شدن جان با پاسخ اشتباه، باز شدن مرحله بعد با پاسخ درست
- صفحه مراحل، قفل بودن مرحله‌های بسته، پروفایل، مأموریت‌ها
- ذخیره ماندن پیشرفت بعد از بستن و باز کردن
- دکمه بازگشت اندروید
- ساخته شدن درست هر ۱۰۰ مرحله (بدون شیء روی هم و بدون تفاوت روی هم)
- بازی کردن مرحله‌های ۱۰، ۴۰، ۷۰، ۱۰۰
- تمام شدن زمان و ادامه با سکه، تمام شدن جان‌ها
- چیدمان در حالت افقی و در صفحه ۳۲۰ پیکسلی

### `admin.test.js`
- درستی SHA-256 و PBKDF2 با بردارهای آزمون رسمی
- تصادفی بودن نمک و ذخیره نشدن رمز به صورت خام
- مخفی بودن بخش‌های نیازمند سرور
- ورود ۷ لمسی، رد شدن رمز کوتاه و رمز اشتباه
- قفل شدن بعد از تلاش‌های ناموفق
- کد بازیابی
- کار کردن هر ۹ تب پنل
- اثر واقعی تنظیمات اقتصاد و سختی روی بازی
- افزودن/ویرایش/حذف تصویر و ماندگاری بعد از بستن بازی
- پشتیبان‌گیری، تشخیص فایل دست‌کاری‌شده، بازگردانی
- بسته شدن خودکار نشست مدیریت

## نکته

تست‌ها روی فایل `app/src/main/assets/index.html` اجرا می‌شوند — همان فایلی که
داخل برنامه اندرویدی است.
