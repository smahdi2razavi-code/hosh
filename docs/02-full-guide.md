## ۱. این پروژه دقیقاً چیست؟

یک بازی موبایلی است که به شکل غیرمعمول ولی خیلی کاربردی ساخته شده:

```
┌─────────────────────────────────────────┐
│  برنامه اندرویدی (Kotlin — ۱۱۵ خط)      │
│  کارش فقط یک چیز است: یک صفحه وب       │
│  تمام‌صفحه باز کن                        │
│  ┌───────────────────────────────────┐  │
│  │  index.html  ←  کل بازی اینجاست   │  │
│  │  • گرافیک (SVG)                   │  │
│  │  • منطق بازی (JavaScript)         │  │
│  │  • ظاهر (CSS)                     │  │
│  │  • صدا (WebAudio)                 │  │
│  │  • ذخیره (localStorage)           │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### چرا اینطوری؟

| مزیت | توضیح |
|---|---|
| **سریع تغییر می‌کند** | یک خط عوض کن، مرورگر را رفرش کن، فوری ببین. لازم نیست هر بار برنامه را بیلد کنی |
| **سبک است** | کل برنامه ۲ مگابایت. هیچ کتابخانه بیرونی ندارد |
| **همه‌جا اجرا می‌شود** | همان فایل در مرورگر، گوشی اندروید، و در آینده iOS یا وب کار می‌کند |
| **یاد گرفتنش آسان است** | HTML/CSS/JS خیلی راحت‌تر از Kotlin+Compose است |

### قیمتش چیست؟

بازی‌های سنگین (سه‌بعدی، فیزیک پیچیده) با این روش خوب نیستند. ولی برای بازی
پازل و سرگرمی مثل این، عالی است.

## ۵. چرخه کار: تغییر بده، ببین

این روش سریع‌ترین راه کار کردن روی بازی است:

```
۱. index.html را در VS Code باز کن
۲. یک چیز را عوض کن و ذخیره کن (Ctrl+S)
۳. در Chrome کلید F5 را بزن
۴. نتیجه را ببین
۵. برگرد به مرحله ۲
```

### ابزار مخصوص برنامه‌نویس‌ها

در Chrome کلید **F12** را بزن تا Developer Tools باز شود:

- تب **Console**: اگر جایی خطا باشد، اینجا قرمز نشان می‌دهد
- دکمه **Toggle device toolbar** (Ctrl+Shift+M): بازی را در اندازه گوشی نشان می‌دهد
- تب **Application ← Local Storage**: اطلاعات ذخیره‌شده بازی را می‌بینی

### پاک کردن پیشرفت هنگام تست

در Console این را بنویس و Enter بزن:

```js
localStorage.clear(); location.reload();
```

### دستورهای مفید در Console

بازی چند ابزار تست دارد:

```js
SM.state()        // دیدن همه اطلاعات بازیکن
SM.diff(45)       // اجرای فوری مرحله ۴۵ بخش تفاوت
SM.guess(12)      // اجرای فوری مرحله ۱۲ بخش حدس
SM.cfg()          // دیدن تنظیمات بازی
SM.admin()        // باز کردن پنل مدیریت
SM.state().coins = 9999; SM.save();   // سکه بگیر
```

## ۶. داخل فایل بازی چه خبر است

فایل `index.html` سه بخش دارد:

| بخش | خط تقریبی | چیست |
|---|---|---|
| `<style>` | ۲۰ تا ۵۰۰ | ظاهر: رنگ‌ها، دکمه‌ها، انیمیشن‌ها |
| `<body>` | ۵۰۰ تا ۶۰۰ | اسکلت صفحه‌ها (بیشترشان با JS پر می‌شوند) |
| `<script>` | ۶۰۰ به بعد | همه منطق بازی |

بخش `<script>` به **۱۵ قسمت شماره‌دار** تقسیم شده. با جست‌وجوی `====` بین آن‌ها
جابه‌جا شو:

| # | نام | چه کاری می‌کند |
|---|---|---|
| ۱ | ابزارهای پایه | تبدیل عدد به فارسی، عدد تصادفی با بذر ثابت |
| ۲ | پیکربندی | `CFG` (قیمت‌ها، جان، مراحل) و `FEATURES` |
| ۲-۱ | رمزنگاری | SHA-256 و PBKDF2 برای پنل مدیریت |
| ۲-۲ | لایه امنیتی | رمز، قفل، نشست، گزارش |
| ۲-۳ | تنظیمات پنل | مقدارهایی که از پنل عوض می‌شوند |
| ۳ | وضعیت بازیکن | ذخیره و بازیابی خودکار |
| ۴ | صدا | ساخت صداها با WebAudio |
| ۵ | پیام و پنجره | توست، پنجره‌ها، کاغذرنگی |
| ۶ | جابه‌جایی صفحه | مدیریت صفحه‌ها و دکمه بازگشت |
| ۷ | مأموریت روزانه | |
| ۸ | پاداش روزانه | |
| ۹ | بانک محتوا | `ITEMS` — تصویرهای بخش حدس |
| ۱۰ | موتور صحنه | `PROPS`، `THEMES`، ساخت تفاوت‌ها |
| ۱۱ | تنظیم مراحل | `diffCfg(n)` و `guessCfg(n)` |
| ۱۲ | بخش پیدا کردن تفاوت | |
| ۱۳ | بخش حدس تصویر | |
| ۱۴ | صفحه‌ها | خانه، مراحل، پروفایل، درباره ما |
| ۱۴-۱ | پنل مدیریت | |
| ۱۵ | راه‌اندازی | اتصال رویدادها |

### تصویرها از کجا می‌آیند؟

**هیچ فایل عکسی در بازی نیست.** تصویرهای بخش «پیدا کردن تفاوت» با کد ساخته
می‌شوند:

```
مرحله ۴۵
   ↓
diffCfg(45)  →  سختی متوسط، ۶ تفاوت، ۷۵ ثانیه
   ↓
SC.build()   →  یک عدد تصادفی با «بذر ثابت» ۴۵
   ↓             (یعنی مرحله ۴۵ همیشه دقیقاً یکسان است)
   ├─ انتخاب تم (شهر)
   ├─ چیدن ۱۳ شیء روی صحنه
   ├─ کپی گرفتن برای تصویر دوم
   └─ تغییر دادن ۶ تا از شیءها
   ↓
دو تصویر SVG
```

برای همین است که ۱۰۰ مرحله فقط چند کیلوبایت جا می‌گیرند.

## ۷. ۱۰ کار رایج با کد نمونه

### ۱) عوض کردن نام بازی

**در بازی** — دنبال این خط بگرد در `index.html`:

```js
var TEAM = { name:'SMRx', game:'سلطان معما', version:'۱٫۱', versionRaw:'1.1' };
```

**زیر آیکون برنامه** — فایل `app/src/main/res/values/strings.xml`:

```xml
<string name="app_name">سلطان معما</string>
```

### ۲) عوض کردن رنگ‌های بازی

بالای بخش `<style>` دنبال `:root` بگرد:

```css
:root{
  --bg1:#2a1c6b;    /* رنگ بالای پس‌زمینه */
  --bg2:#150e35;    /* رنگ پایین پس‌زمینه */
  --gold:#FFC94A;   /* رنگ سکه */
  --pink:#FF5D8F;
  --cyan:#2FD8D0;
  --green:#43D97B;
}
```

فقط همین چند عدد را عوض کن — کل بازی رنگ عوض می‌کند.

### ۳) اضافه کردن تصویر تازه به بخش حدس

**راه آسان:** از پنل مدیریت ← تب محتوا ← فرم «تصویر تازه»

**راه کدی:** در بخش ۹ به آرایه `ITEMS` اضافه کن:

```js
var ITEMS=[
  ['🐱','گربه','animal'],
  ['🍕','پیتزا','food'],
  ['🥁','طبل','thing'],      // ← خط تازه
];
```

قالب: `['ایموجی','نام فارسی','دسته']`

دسته‌های موجود: `animal` `food` `place` `thing` `fantasy` `sport` `nature` `car` `fruit` `job`

### ۴) بیشتر کردن تعداد مراحل

در بخش ۲:

```js
var CFG = {
  TOTAL_STAGES:100,   // ← این را ۲۰۰ کن
};
```

مرحله‌ها خودکار ساخته می‌شوند، پس چیز دیگری لازم نیست.

### ۵) عوض کردن زمان و سختی مراحل

**راه آسان:** پنل مدیریت ← تب سختی

**راه کدی:** در بخش ۲-۳:

```js
d:{ e:25,          // مرحله‌های ۱ تا ۲۵ آسان
    m:55,          // ۲۶ تا ۵۵ متوسط
    h:80,          // ۵۶ تا ۸۰ سخت، بقیه خیلی سخت
    baseTime:100,  // زمان مرحله ۱ (ثانیه)
    timeDrop:0.55, // هر مرحله چقدر زمان کم شود
    minTime:35,    // کمترین زمان ممکن
    diffBase:3,    // تعداد تفاوت مرحله ۱
    diffStep:12,   // هر ۱۲ مرحله یک تفاوت بیشتر
    maxDiff:10 }
```

### ۶) عوض کردن قیمت‌ها

در بخش ۲ (یا از پنل مدیریت ← اقتصاد):

```js
var CFG = {
  MAX_LIVES:5,
  LIFE_MS:10*60*1000,   // هر ۱۰ دقیقه یک جان
  HINT_COST:50,         // قیمت راهنما
  FIFTY_COST:50,        // قیمت حذف گزینه
  CLEAR_COST:80,        // قیمت واضح‌تر کردن
  REVIVE_COST:100,      // قیمت ادامه بعد از شکست
  REFILL_COST:150       // قیمت پر کردن جان
};
```

### ۷) اضافه کردن شیء تازه به صحنه‌ها

سه قدم در بخش ۱۰:

**الف) تابع رسم** — به `PROPS` اضافه کن. مبدأ مختصات پایین وسط شیء است:

```js
umbrella:function(o,C,D){
  var s='<rect x="-0.8" y="-14" width="1.6" height="14" fill="#7a4a21"/>';
  s+='<path d="M-11,-14 A11,9 0 0 1 11,-14 Z" fill="'+C+'"/>';
  if(o.v===1) s+='<path d="M-11,-14 h22" stroke="'+D+'" stroke-width="1.4"/>';
  if(o.d) s+='<circle cx="0" cy="-17" r="1.8" fill="'+D+'"/>';
  return s;
},
```

**ب) مشخصات** — به `META` و `COL`:

```js
umbrella:{r:13,oy:-9,f:0},              // شعاع لمس، مرکز دیداری، قرینه‌شدنی؟
umbrella:[0,360,70,90,55,66],           // محدوده رنگ [hMin,hMax,sMin,sMax,lMin,lMax]
```

**ج) گذاشتن در تم** — اسمش را در لیست `land` یا `air` یکی از تم‌ها بنویس:

```js
{id:'beach',name:'ساحل', … land:['boat','ball','shell','umbrella']},
```

### ۸) اضافه کردن تم صحنه تازه

در بخش ۱۰ به `THEMES` اضافه کن:

```js
{id:'forest', name:'جنگل',
 sky:[[150,60,55],[120,50,75]],   // رنگ آسمان [بالا، پایین] به صورت HSL
 ground:[100,40,32], gy:130,       // رنگ زمین و ارتفاع خط افق
 air:['bird','cloud','butterfly'], // شیءهای آسمان
 land:['tree','bush','flower']}    // شیءهای زمین
```

### ۹) خاموش/روشن کردن بخش‌های نیازمند سرور

در بخش ۲:

```js
var FEATURES = {
  leaderboard:false,   // رتبه‌بندی
  shop:false,          // فروشگاه
  online:false,        // بازی آنلاین
  …
};
```

هر کدام `false` باشد، در صفحه اصلی دیده نمی‌شود و صفحه‌اش هم باز نمی‌شود.
وقتی سرورت آماده شد `true` کن. ([۰۷ — افزودن سرور](07-server.md))

### ۱۰) عوض کردن متن‌ها

همه متن‌ها فارسی و داخل کد هستند. با Ctrl+F متن را پیدا کن و عوض کن.
مثلاً برای پیام خوش‌آمد، دنبال `به سلطان معما خوش آمدی` بگرد.

## ۹. تست کردن قبل از انتشار

### چک‌لیست دستی

- [ ] هر دو بخش بازی را چند مرحله بازی کن
- [ ] یک مرحله را عمداً بباز (زمان تمام شود) و «ادامه با سکه» را امتحان کن
- [ ] همه جان‌ها را تمام کن و ببین پیام درست می‌آید
- [ ] راهنما، حذف گزینه و واضح‌تر کردن را امتحان کن
- [ ] بازی را ببند و دوباره باز کن — پیشرفت باید سر جایش باشد
- [ ] دکمه بازگشت گوشی را در همه صفحه‌ها بزن
- [ ] گوشی را بچرخان (اگر قفل نکردی)
- [ ] روی یک گوشی کوچک (۳۲۰ پیکسل) هم ببین

### تست خودکار

پروژه با تست خودکار روی مرورگر واقعی بررسی شده. اگر Node.js داری:

```bash
npm i playwright
node test.js        # ۳۳ تست بازی
node test-admin.js  # ۲۷ تست پنل مدیریت و امنیت
```

## ۱۰. ساخت نسخه نهایی

### ساخت کلید امضا (فقط یک بار در عمر برنامه)

```bash
keytool -genkey -v -keystore sultan.jks -keyalg RSA \
        -keysize 2048 -validity 10000 -alias sultan
```

از تو رمز و چند سؤال می‌پرسد. جواب بده و **فایل `sultan.jks` و رمزش را
برای همیشه نگه دار** — اگر گمش کنی دیگر نمی‌توانی برنامه‌ات را به‌روزرسانی کنی.

### معرفی کلید به پروژه

فایل `keystore.properties.example` را کپی کن، اسمش را بگذار `keystore.properties`
و پرش کن:

```properties
storeFile=C:/keys/sultan.jks
storePassword=رمزی که گذاشتی
keyAlias=sultan
keyPassword=رمزی که گذاشتی
```

> این فایل در `.gitignore` هست و در گیت نمی‌رود. هرگز رمزت را در گیت نگذار.

### ساخت خروجی

```bash
./gradlew assembleRelease     # فایل APK — برای بازار، مایکت، نصب مستقیم
./gradlew bundleRelease       # فایل AAB — برای گوگل‌پلی
```

خروجی‌ها:

```
app/build/outputs/apk/release/app-release.apk
app/build/outputs/bundle/release/app-release.aab
```

## ۱۳. مشکلات رایج

<div align="right">

**❓ Gradle sync خطا می‌دهد / کتابخانه دانلود نمی‌شود**
در `gradle.properties` مقدار `useIranMirror=true` بگذار و دوباره Sync کن.

**❓ «SDK location not found»**
اندروید استودیو را باز کن؛ خودش SDK را نصب می‌کند. یا فایل `local.properties`
بساز با محتوای `sdk.dir=مسیر/SDK`.

**❓ برنامه نصب می‌شود ولی صفحه سفید است**
یعنی در جاوااسکریپت خطا هست. گوشی را با کابل وصل کن، در Chrome کامپیوتر آدرس
`chrome://inspect` را باز کن و خطا را در Console ببین.

**❓ فونت فارسی درست نشان داده نمی‌شود**
مطمئن شو `vazir.ttf` و `vazir-bold.ttf` در پوشه `assets` هستند.

**❓ صدا پخش نمی‌شود**
صدا فقط بعد از اولین لمس صفحه فعال می‌شود (قانون مرورگرها). اگر باز هم نبود،
از پروفایل بازی گزینه صدا را چک کن.

**❓ رمز پنل مدیریت را فراموش کردم**
در صفحه ورود روی «رمز را فراموش کرده‌ام» بزن و کد بازیابی را وارد کن.
اگر آن را هم نداری: در Console مرورگر بنویس
`localStorage.removeItem('sultan_sec_v1')` — روی گوشی راهش پاک کردن داده‌های
برنامه از تنظیمات اندروید است.

**❓ تغییری که دادم دیده نمی‌شود**
در مرورگر Ctrl+F5 بزن (رفرش کامل). در اندروید استودیو برنامه را حذف و دوباره
نصب کن.
