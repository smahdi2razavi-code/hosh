## 🎮 بخش‌های بازی

### 🔍 پیدا کردن تفاوت
دو تصویر تقریباً یکسان کنار هم؛ باید تفاوت‌ها را پیدا کنی.

- ۱۰۰ مرحله، هر مرحله ۳ تا ۱۰ تفاوت
- تصویرها **با کد ساخته می‌شوند** (SVG) — هیچ فایل عکسی در بازی نیست
- ۷ تم صحنه: پارک، ساحل، شهر، زیر دریا، فضا، اتاق، مزرعه
- ۲۹ نوع شیء با ۷ نوع تفاوت: رنگ، حذف، افزودن، اندازه، شکل، جزئیات، قرینه
- زمان محدود، راهنما با سکه، جریمه برای لمس اشتباه، ادامه با سکه بعد از شکست

### 🖼️ حدس تصویر
تصویر تار و پوشیده است و کم‌کم باز می‌شود؛ باید حدس بزنی چیست.

- ۱۰۰ مرحله، ۱۶۰+ تصویر در ۱۰ دسته
- سیستم جان (۵ جان، هر ۱۰ دقیقه یکی شارژ می‌شود)
- کمک‌های سکه‌ای: حذف یک گزینه، واضح‌تر کردن تصویر

### 📦 بقیه بخش‌ها
سکه · امتیاز · سطح · ستاره مرحله · مرحله ویژه هر ۱۰ مرحله ·
پاداش روزانه ۷ روزه · مأموریت‌های روزانه · پروفایل · درباره ما

هیچ صفحه‌ای اسکرول ندارد — همه چیز در یک نمای گوشی جا می‌شود.
مرحله‌ها به ترتیب باز می‌شوند و مرحله قفل به هیچ روشی اجرا نمی‌شود.

## 🚀 اجرای سریع

```bash
git clone https://github.com/smahdi2razavi-code/hosh.git
cd hosh
./gradlew assembleDebug
```

یا پوشه پروژه را در **Android Studio** باز کن و دکمه ▶ Run را بزن.

> فقط می‌خواهی بازی را ببینی؟ فایل `app/src/main/assets/index.html` را مستقیم در
> مرورگر باز کن — همه بازی همان‌جا اجرا می‌شود.

## 🛠 پنل مدیریت (سایت لپ‌تاپ)

پنل مدیریت **داخل بازی نیست**؛ یک سایت جداست که روی لپ‌تاپ خودت اجرا می‌شود:

```
admin-panel/index.html  ←  روی لپ‌تاپ دوبار کلیک کن
```

با آن تنظیمات و محتوای بازی را عوض می‌کنی و یک فایل `config.js` می‌سازی که در
`app/src/main/assets/` می‌گذاری و بازی را دوباره می‌سازی.

| بخش | چه کاری می‌کند |
|---|---|
| 🎮 بازی | نام بازی، نام تیم، نسخه |
| 💰 اقتصاد | قیمت راهنما، تعداد جان، ضریب سکه و امتیاز |
| 🎚 سختی | زمان، تعداد تفاوت، مرز درجه‌ها + پیش‌نمایش زنده |
| 🖼 محتوا | افزودن/ویرایش/حذف تصویرهای بخش حدس |
| 🎯 مأموریت و پاداش | هدف و جایزه مأموریت‌ها و پاداش ۷ روزه |
| 🧩 قابلیت‌ها | روشن/خاموش کردن بخش‌های نیازمند سرور |
| 📤 خروجی | ساخت و دانلود `config.js` |
| 📝 متن فروشگاه | متن آماده مایکت و کافه بازار |
| 🛡 امنیت | رمز، قفل خودکار، گزارش کارها |

قفل پنل: رمز با **PBKDF2-SHA256** و ۱۵۰۰۰ تکرار و نمک تصادفی ذخیره می‌شود، با
قفل تدریجی بعد از تلاش ناموفق و بستن خودکار نشست.
جزئیات و محدودیت‌ها در [۰۴ — امنیت](docs/04-security.md).

> چون پنل از بازی جدا شد، فایل نصبی بازی **هیچ رمز و هیچ درِ مخفی‌ای ندارد**.
