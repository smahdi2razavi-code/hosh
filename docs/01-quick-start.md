# ۰۱ — شروع سریع (۵ دقیقه)

## راه ۱ — دیدن بازی در مرورگر (سریع‌ترین، ۳۰ ثانیه)

کل بازی یک فایل است. کافی است این فایل را باز کنی:

```
app/src/main/assets/index.html
```

روی کامپیوتر: راست‌کلیک ← Open with ← Chrome
روی گوشی: فایل را در حافظه گوشی بگذار و با مرورگر بازش کن.

✅ همه چیز کار می‌کند: هر دو بخش بازی، پنل مدیریت، ذخیره پیشرفت.
❌ فقط لرزش گوشی و آیکون برنامه را ندارد.

**بهترین کاربرد:** وقتی می‌خواهی چیزی را تغییر بدهی و نتیجه را فوری ببینی.

---

## راه ۲ — ساخت فایل نصبی با یک دستور

اگر جاوا نصب داری (JDK 17 یا بالاتر):

```bash
git clone https://github.com/smahdi2razavi-code/hosh.git
cd hosh
./gradlew assembleDebug
```

در ویندوز به‌جای `./gradlew` بنویس `gradlew.bat`.

فایل خروجی اینجاست:

```
app/build/outputs/apk/debug/app-debug.apk
```

این فایل را به گوشی بفرست و نصب کن.

> بار اول چند دقیقه طول می‌کشد چون Gradle و کتابخانه‌ها دانلود می‌شوند.
> دفعه‌های بعد کمتر از یک دقیقه است.

---

## راه ۳ — اندروید استودیو (کامل)

### ۱. نصب
از [developer.android.com/studio](https://developer.android.com/studio) اندروید استودیو را بگیر و نصب کن.
جاوا (JDK) همراهش نصب می‌شود، جدا لازم نیست.

### ۲. باز کردن پروژه
اندروید استودیو ← **Open** ← پوشه `hosh` را انتخاب کن ← OK

بار اول پیام «Gradle sync» می‌آید؛ صبر کن تمام شود (پایین صفحه نوار پیشرفت دارد).

### ۳. اجرا
- **روی گوشی واقعی:** در گوشی «حالت توسعه‌دهنده» و «USB debugging» را روشن کن،
  با کابل وصلش کن، اسم گوشی در نوار بالا ظاهر می‌شود ← ▶ Run
- **روی شبیه‌ساز:** Device Manager ← Create Device ← یک گوشی انتخاب کن ← ▶ Run

---

## اگر دانلود کتابخانه‌ها گیر کرد

بعضی وقت‌ها دسترسی به سرورهای گوگل مشکل دارد. در این حالت فایل
`gradle.properties` را باز کن و این خط را عوض کن:

```properties
useIranMirror=true
```

بعد در اندروید استودیو: **File ← Sync Project with Gradle Files**
