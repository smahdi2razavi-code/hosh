# ۰۸ — متن فروشگاه (مایکت، کافه بازار، گوگل‌پلی)

متن‌های آماده برای ثبت بازی. همین‌ها را در پنل مدیریت (بخش «متن فروشگاه») هم
می‌توانی بسازی و کپی کنی.

</div>

---

## عنوان برنامه

```
سلطان معما — بازی پازل و سرگرمی فارسی
```

اگر فروشگاه عنوان کوتاه‌تر می‌خواهد:

```
سلطان معما
```

• مأموریت‌های روزانه با جایزه

## نکته‌های ثبت

- **عنوان را تغییر نده** بعد از انتشار؛ کاربران با همان اسم پیدایت می‌کنند.
- در توضیح کامل، **خط اول مهم‌ترین است** — در فهرست نتایج همان دیده می‌شود.
- کلمات کلیدی را داخل متن توضیح هم بیاور، نه فقط در فیلد جدا.
- بعد از انتشار، به نظرهای کاربران جواب بده؛ روی رتبه‌بندی فروشگاه اثر دارد.
